Dobrodošli u Mapu Zgrada

Za rad mape potreban je besplatan Mapbox API ključ (50.000 učitavanja mjesečno besplatno).

  1. Otvori mapbox.com/signup i napravi račun
  2. Na Account stranici kopiraj Default public token
  3. Zalijepi ga u polje ispod (počinje sa pk.)

Ključ se sprema samo u tvoj preglednik (localStorage).
